# Echi delle Ceneri — prototipo iOS

Un prototipo originale 2D dark-fantasy per iPhone, con combattimento laterale e atmosfera gotica. È ispirato al genere soulslike e metroidvania, senza usare personaggi, nomi, asset o mappe di Elden Ring/Castlevania.

## Controlli
- Frecce sinistra/destra: movimento
- SALTO: salta
- ATTACCO: colpisci il Custode delle Rovine
- Pulsante in alto a destra: ricomincia

## Aprire in Xcode
1. Su un Mac, apri Xcode e crea un nuovo progetto iOS > App chiamato `EchiDelleCeneri`.
2. Seleziona SwiftUI come interfaccia e Swift come linguaggio.
3. Sostituisci il file `ContentView.swift` con quello incluso in questa cartella.
4. Imposta Deployment Target iOS 16 o superiore.
5. Seleziona un simulatore iPhone oppure collega il tuo iPhone, scegli il team di firma in Signing & Capabilities e premi Run.

## Nota
Questo è un prototipo giocabile iniziale, non ancora un gioco commerciale completo. La grafica è disegnata proceduralmente con SpriteKit. Per una release completa servono ulteriori livelli, boss, animazioni, audio, salvataggi, menu, test su dispositivi e bilanciamento.
